# 飞针机采集器窗口与同步记录设计

## 目标

把现有飞针机采集程序改为双击即可打开的 Windows 桌面窗口。界面参考用户提供的 MES Mock 截图：上方显示配置和运行控制，下方显示记录列表与选中记录的详情。操作员能在窗口中配置采集目录和 QMS、启动或停止采集、查看同步成功与失败记录，并在重启后查看历史。关闭窗口即停止采集。现有文件解析、去重、本地待发队列、检查点和 QMS Telemetry v1 协议保持原有行为。

截图中的接口响应编辑器、监听 IP 和端口属于 MES Mock，不适用于飞针机采集器，不加入新窗口。

## 程序形态与窗口

发布目录中的 `FlyingProbeCollector.exe` 改为 .NET Framework 4.x WinForms 程序，直接双击会显示主窗口；另保留 `FlyingProbeCollector.Console.exe` 供命令行或无人值守场景使用。两者共用采集核心、INI 配置、本地队列、检查点和历史记录文件，同时运行时仍由已有独占锁阻止重复采集。

主窗口采用可调整大小的三段布局：

1. **采集配置**：采集根目录、QMS 地址、网关令牌、可选 Bearer Token、扫描间隔；令牌输入框遮挡内容。提供“保存配置”“启动采集”“停止采集”及当前状态。运行时配置不可编辑，先停止再修改。INI 文件仍是配置来源，窗口保存时原子写入；保留未修改的配置项与现场值，不把真实令牌写入仓库示例文件。
2. **同步概况**：当前状态、待发送数量、最近成功时间、最近错误。配置缺失或无效时窗口仍能打开，显示“待配置”和明确的字段错误；有效配置在打开窗口后自动开始采集。共享目录或 QMS 暂时不可用时窗口保持打开并显示重试状态。
3. **同步记录**：表格按时间显示入队、上报成功、上报失败及重试。列含时间、设备、料号、已测/好/坏板数、结果、HTTP 状态、记录号。选中行可查看不含认证头的 QMS 请求事件 JSON，以及响应摘要或失败原因。提供日期筛选和向前加载历史；默认显示最近记录，避免大量记录卡住界面。

关闭窗口时先停止轮询与发送、释放文件锁，再退出；停止请求会阻止下一条待发事件开始发送。若当前请求正在等待 QMS 响应，界面显示“正在停止”，最多等待已配置的请求超时。停止采集后仍可查看历史记录和修改配置。

## 数据流与历史保存

从当前控制台入口抽出单进程采集运行器，供窗口和控制台入口调用。扫描、发送以及文件写入在后台工作线程执行；窗口更新通过 WinForms UI 线程调度，界面不因网络超时或共享目录访问而冻结。扫描器和发送器发布结构化状态事件，不从自由格式日志文字反推同步结果。

待发送队列 `pending-events.json` 和检查点 `scan-checkpoints.json` 继续是可靠性状态来源。新增 `data/history/yyyy-MM-dd.jsonl`，按日期追加 JSON Lines 历史，记录时间、`recordNo`、设备、料号、三个板数、测试时间、事件类型、阶段、结果、HTTP 状态、请求事件 JSON 及最多 8 KiB 的响应摘要。历史记录不保存网关令牌、Bearer Token 或完整请求头。每次上报尝试均记录结果，因此同一快照重试可出现多行。旧记录保留在本地磁盘，不自动删除；界面按日期和分页读取，不一次加载全部内容。

QMS 返回 `2xx` 后，先持久记录成功，再从待发队列移除；历史写入失败时保留队列中的事件，靠相同 `recordNo` 重试，避免已成功上报却没有可追溯记录。非 `2xx`、超时和网络错误写失败记录并保留队列；历史写入失败时仍保留队列，在界面显示本地记录故障。入队记录写入失败不能丢失已持久化的待发事件。历史文件某行损坏时界面标明读取错误，跳过该行，队列与检查点的严格损坏处理规则不变。

## 配置与兼容

首次运行可以打开空配置窗口，不因 `GatewayToken` 的示例值而立即退出。保存配置时校验目录路径格式、QMS URL、令牌和数值范围，并展示错误；不要求共享目录此时可访问，以便共享目录故障时仍可启动并重试。配置中的相对路径仍相对 INI 所在目录解析。默认共享目录为 `\\Scbgx\数字化\飞针机`。GUI 与控制台版共用同一份 INI，但不能并发运行同一队列。构建脚本保留现场已有 INI 内容；发布包同时包含 GUI、控制台版、启动脚本、示例 INI 和说明文档。

## 验证

- 保持原有解析、稳定文件检测、队列恢复、QMS 上传与重试测试通过。
- 用临时目录和本地 HTTP 服务验证历史文件跨重启可读、成功记录先于出队、失败与重试的多行记录、令牌不进入历史、历史写失败仍保留队列。
- 验证无效配置时 GUI 能打开并提示、有效配置时启停状态正确、关闭后释放锁；在 Windows 上检查表格与详情在常见 DPI 和窗口大小下可用。
- 验证构建发布目录的 GUI 与控制台程序均存在，现场 INI 重建后不被覆盖。
- 现场共享目录与真实 QMS 映射仍需在有权限的电脑上核验。
